# LifeHub - 個人隨身工作站 (Mobile PWA)

專為個人手機使用打造的**漸進式模組化行動應用（PWA）**。無須註冊登入、啟動飛快、支援離線運作，資料 100% 儲存在本機，並具備完整 JSON 匯出備份與還原機制。

---

## 🌟 核心特色

1. **跨平台原生體驗 (iOS & Android)**：
   - 支援加入手機主畫面（Add to Home Screen），全螢幕沉浸體驗，無瀏覽器網址列干擾。
   - 針對 iPhone 動態島/瀏海及底部手勢條進行安全區域（Safe Area Insets）適配。
   - 輕量觸感反饋（Haptic Feedback）與流暢切換動畫。
2. **完全離線與極致隱私 (Offline-First)**：
   - 搭載 Service Worker 離線快取，無網路時仍能正常啟動與操作。
   - 資料保存在手機本機 LocalStorage，不經過任何第三方雲端伺服器。
   - 內建一鍵「匯出 JSON 備份」與「匯入還原」，隨時可在不同裝置間轉移或備份。
3. **高擴充性模組化架構 (Pluggable Modules)**：
   - 每個功能皆為獨立模組（位於 `js/modules/` 目錄），如 `dashboard.js`、`tasks.js`、`settings.js`。
   - 後續您可以隨時向 AI 提出想要的新功能（如：個人記帳、習慣追蹤、每日靈感筆記、番茄鐘等），AI 可直接無縫掛載新模組分頁，不影響既有功能！

## 🚀 快速啟動與手機連線

### 步驟 1：啟動本機伺服器
在專案根目錄執行：
```bash
python serve.py
```
終端機會自動偵測您的電腦區域網路 IP（例如 `http://192.168.1.132:8080`）。

### 步驟 2：手機瀏覽器連線（需與電腦處於相同 Wi-Fi）
1. 打開手機上的 **Safari (iPhone)** 或 **Chrome (Android)**。
2. 在網址列輸入終端機顯示的網址（如 `http://192.168.1.132:8080`）。

### 步驟 3：安裝到手機主畫面
- **iPhone (iOS Safari)**：
  1. 點擊瀏覽器底部正中間的「**分享**」按鈕（向上箭頭 📤）。
  2. 向下滑動找到並點選「**加入主畫面 (+ Add to Home Screen)**」。
  3. 點擊右上角「**新增**」。
- **Android (Chrome)**：
  1. 點擊右上角「**三個點選單 (⋮)**」。
  2. 點選「**安裝應用程式**」或「**加到主畫面**」。

完成後，手機桌面上就會出現 **LifeHub** 專屬圖示，點擊即可像一般 App 一樣全螢幕開啟使用！

## 📁 專案架構

```
4_apps/
├── index.html              # PWA 主頁面架構與行動適配
├── manifest.json           # Web App Manifest 配置檔
├── sw.js                   # Service Worker 離線快取引擎
├── serve.py                # 智慧本地伺服器（自動取得區網 IP）
├── css/
│   └── styles.css          # 行動端專用樣式、iOS 安全區與動畫
├── js/
│   ├── app.js              # 核心路由器、模組註冊中心、彈窗與狀態管理
│   ├── storage.js          # 本地儲存引擎、種子資料、JSON 匯出/匯入備份
│   └── modules/
│       ├── dashboard.js    # 模組1：總覽（問候、今日進度、焦點事項、模組架構預覽）
│       ├── tasks.js        # 模組2：待辦事項（新增/編輯/刪除、優先級、標籤、搜尋、過濾）
│       └── settings.js     # 模組3：設定（外觀主題切換、JSON 備份還原、安裝教學）
└── icons/                  # 應用程式各尺寸圖示 (192x192, 512x512, apple-touch-icon)
```

## 🛠️ 未來功能擴充方式

當您希望加入新功能時，只需告訴 AI：
> 「我想要增加一個 **個人記帳** 功能，希望有支出收入記錄、類別統計圖表」
> 「我想要一個 **習慣追蹤** 功能，可以記錄每天有沒有打卡」

AI 會在 `js/modules/` 新增對應的模組檔案，並在 `app.js` 註冊該模組，您的 App 就會立刻擁有全新功能！
